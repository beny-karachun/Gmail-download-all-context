# Mailpack Local privacy policy

Mailpack Local processes selected Gmail conversation data locally in the user's Chrome browser.

- It does not transmit, sell, share, or upload Gmail data.
- It does not use analytics, advertising, telemetry, or remote executable code.
- It briefly stores the selected conversation descriptors in Chrome's session-only extension storage while opening the export page, then deletes that job record.
- It reads only the Gmail conversations selected by the user for the requested export.
- It saves the resulting ZIP through Chrome's Downloads API to a location chosen by the user.

Removing the extension removes its extension storage. ZIP files already downloaded remain wherever the user saved them.
